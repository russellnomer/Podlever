**2. Architecture Overview**

* **Framework:** Next.js 15 App Router, TypeScript strict, Tailwind, Zod. shadcn/ui initialized non-interactively (init only; no components installed).
* **Layering (mandatory):** Server Action / Route Handler / Job → Service → Repository → Drizzle. Server Actions, Route Handlers, and Jobs never call Repositories directly. `/jobs` exists as an empty, structured placeholder only.
* **Persistence:** Replit PostgreSQL via Drizzle ORM; minimum normalized schema (User, Episode, Asset, PipelineEvent) designed for additive evolution.
* **Identity:** A narrow AuthProvider interface in `/providers`; concrete implementation chosen only after Environment Discovery + Human Checkpoint. Middleware reads identity only — never touches the database.
* **Validation strategy:** Single source of Zod schemas per domain entity in `/types`.
